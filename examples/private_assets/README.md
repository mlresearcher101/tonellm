# Example private assets

These files show the shape expected by tonellm at runtime. The real versions
live outside the repository (e.g. `~/.config/tonellm/`) so the tone knowledge
is not public.

Copy these to `~/.config/tonellm/` and fill in your own values, or set the
`TONELLM_SYSTEM_PROMPT` and `TONELLM_MAPPINGS` environment variables.
